## 受入条件
| ID | 操作/入力 | 合格条件 |
|---|---|---|
| AC01 | must1件＋optionalから生成 | 全採用可能案でmust保持、固定時刻も保持 |
| AC02 | 時間案 | visit集合を保持し、時刻/順序の意味ある差と根拠がある |
| AC03 | 場所案 | optionalの実交換、希望の体験との関係、違いと負担を表示 |
| AC04 | ja/enの自由文 | 候補ID内の解釈、具体値の創作なし、本人が訂正可能 |
| AC05 | 曖昧/矛盾した希望 | unresolved、既存mustや数値を自動上書きしない |
| AC06 | AI未使用/意図API失敗 | フォームで確認・生成を継続できる |
| AC07 | 同一Spotの待ち時間 | 元案と代替案で同じ仮定。時刻変更だけで減少しない |
| AC08 | 待ち時間なし/交換先unknown | 未算入を表示、空き/0分短縮の偽表示なし |
| AC09 | 回避窓/固定時刻衝突 | 固定時刻維持、残る回避窓重複と不利益を表示 |
| AC10 | 営業不明/閉店/予約未確保 | 確認済み訪問として通さず、理由を返す |
| AC11 | 歩行/終了上限を縮小 | 旅行前refineへ反映。却下/失敗では採用中条件を維持 |
| AC12 | 元案不成立/代替案なし | 不正な元案の採用/改善率なし、理由と変更候補 |
| AC13 | 他uidの資源取得/採用 | 404、内容漏洩なし |
| AC14 | 同採用keyを再送/別key古version | 前者は1回分の採用、後者は409と再確認 |
| AC15 | Gemini説明timeout/不正Fact | locale別定型fallback、有効旅程は維持 |
| AC16 | 日英で入力→採用→再読込 | 双方で完走、ID/数値/hard constraintは同じ |
| AC17 | Maps失敗/360px/keyboard | 一覧で操作完走、押せない/読めない主要要素なし |
| AC18 | 条件変更 | fixture固定の見せかけでなく、実engineの結果と理由が変わる |
| AC19 | 2案不足/同内容候補 | 有効で異なる案だけ返し、不足理由を表示 |
| AC20 | 実演シナリオ | 時間案と場所案の両方を実HTTP/Gemini/保存で説明できる |
